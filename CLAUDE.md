## Жёсткие правила
- **Не выдумывать** данные: отзывы, цифры, цитаты, результаты пилота и теста. Только реальное и сверенное (факты — `HANDOFF.md`, раздел 4).
- **Судьям — честно**: языковую модель мы не обучали, это Gemini (Google) и запасная Groq; наше — всё вокруг (инструкция под казахстанские схемы, правила-страховка, проверка цитат, цепочка моделей, бот, семьи, тревоги). Участникам пилота говорим «ИИ Saqta» без названий компаний и просим не присылать свои коды и пароли.
- Ключи и токены — **только в Vercel** (env, тип Secret). Никогда не класть их в репозиторий и не просить прислать в чат.
- Режим сайта `?demo=1` (печатает заготовленный текст) в видео 2-го тура **не использовать**: судьи требуют демо без заготовок и без монтажа.
- Тестовые прогоны анализа — с флагом `eval: true` (или `web/scripts/eval.mjs`), чтобы не портить статистику пилота.

## Как устроено (кратко)
- `web/` — сайт (React + Vite + Tailwind) и сервер: одна функция Vercel `web/server/handler.js` на все `/api/*`.
- Анализ: `web/server/analyze.js` = модель (`llm.js`: Gemini → параллельно Groq через 1,5 с) + правила (`web/src/engine.js`). Голос и скриншоты → текст: `media.js`. Бот: `telegram.js`. Хранилище: `store.js` (Upstash Redis).
- Прод: https://saqta-delta.vercel.app · бот @Saqta_kz_bot · репозиторий https://github.com/adekaa11/saqta
- Проверка, что всё живо: `/api/health` (видны модели и бот), метрики пилота: `/#/stats`.

## Команды
Локальный запуск (любая ОС): `cd web && npm install && npm run dev` → http://localhost:5173. Без ключей анализ работает на правилах.

Деплой на прод (Windows и Mac одинаково, нужен вход в Vercel-аккаунт Адильжана, `npx vercel@latest login`):
```
cd web
npx vite build
node scripts/build-vercel.mjs
cd deploy
npx vercel@latest deploy --prebuilt --prod --yes
```
Обычный `vercel deploy` без `--prebuilt` на Windows падает (симлинки). После добавления env-переменной в Vercel нужен новый деплой. Если деплоит Дан — сначала предупредить Адильжана.

Тест точности: `cd web && node scripts/eval.mjs ../eval/<файл>.csv --label <название>` (CSV — из Google-таблицы «Saqta — 30 реальных сообщений для теста»).

Коммиты — по-русски, понятным языком; пушить в `main` (работаем вдвоём, без веток), перед работой — `git pull`.
