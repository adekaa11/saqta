# Дан: как работать с Claude над Saqta на своём Mac

Займёт 10–15 минут один раз. Тогда Claude будет знать весь проект и помогать тебе так же, как Адильжану.

## 1. Установи программы
1. **Claude** (приложение для Mac): https://claude.ai/download → войди в аккаунт, данные даст Адильжан. Открой вкладку **Code**.
2. **Node.js** (нужен для запуска сайта и тестов): https://nodejs.org → кнопка **LTS** → установи как обычную программу.
3. **Git**: открой программу «Терминал» и вставь
   ```
   xcode-select --install
   ```
   Появится окно — нажми «Установить». Если пишет, что уже установлено, всё в порядке.

## 2. Скачай проект
В «Терминале»:
```
cd ~/Documents
git clone https://github.com/adekaa11/saqta.git
```
Появится папка `Documents/saqta`.

## 3. Открой проект в Claude
1. В приложении Claude, во вкладке **Code**, выбери папку `Documents/saqta`.
2. Первое сообщение: **«Я Дан. Прочитай HANDOFF.md и мои задания в pilot/README.md»**.

Claude прочитает файл `CLAUDE.md` и поймёт, что это ты: будет объяснять проще и давать команды для Mac.

## Что можно просить у Claude
- «Объясни простыми словами, как работает Saqta. Задай мне вопросы как судья» — подготовка к защите.
- «Помоги составить сценарий/текст озвучки по defense/video-round2.md».
- «Вот сообщение, которое прислала тётя, — проверь, подходит ли оно в таблицу 30 сообщений».
- «Бот ответил странно — вот скриншот, что случилось?»

## Перед каждой работой
Чтобы у тебя была последняя версия того, что сделал Адильжан, попроси Claude: **«Сделай git pull»**.

## Чего не делать без Адильжана
- Не выкладывать изменения на сайт (деплой).
- Не менять настройки Vercel, Google-таблиц и бота.
- Не вставлять никакие ключи и пароли в файлы проекта.
