# Тест точности

1. Дан заполняет Google-таблицу «Saqta — 30 реальных сообщений для теста» (ссылка в `pilot/README.md`).
2. Таблица → Файл → Скачать → CSV (.csv) → положить сюда, например `eval/real-30.csv`.
3. Запуск из папки `web`:
   ```
   node scripts/eval.mjs ../eval/real-30.csv --label реальные-30
   ```
4. Отчёт появится здесь: `eval/report-<дата>-реальные-30.md` — метрики, промахи, таблица всех сообщений.

Тестовые запросы помечены флагом `eval` и не попадают в статистику пилота и тревоги семьи.

`sample-synthetic.csv` и отчёт по нему — только проверка, что скрипт работает (сообщения придуманы командой). В презентацию не брать.

## Результаты на реальных сообщениях (26.11.2026)

Набор `real-smi-32.csv`: 32 настоящих сообщения из казахстанских СМИ (скриншоты, цитаты SMS, пересказы звонков пострадавших; у каждого ссылка на статью). 25 мошеннических, 7 обычных — среди обычных специально трудные: настоящие SMS от 1414/eGov/Kaspi/МВД со словами «код», «AnyDesk», «ограничение». Собрал Дан с помощью ИИ-ассистента (поиск в СМИ), проверено командой.

| Прогон | Мошеннические: предупредили | Обычные: ложная тревога «мошенники» | Всего верных |
|---|---|---|---|
| Первый (`report-2026-11-26-СМИ-32.md`) | 19 / 25 (76%) | 6 / 7 (86%) | 63% |
| После исправлений (`report-2026-11-26-СМИ-32-итог.md`) | **22 / 25 (88%)** | **1 / 7 (14%)** | **88%** |

**Что изменили по итогам теста:** модель путала настоящие уведомления (код входа от 1414, предупреждение МВД «не устанавливайте AnyDesk») с мошенничеством → в инструкцию добавили принцип «код, который пришёл вам, — норма; опасно, когда его просят назвать», правила научили не считать предупреждения банков и МВД признаком обмана. Добавили схемы, которые модель пропускала: «вернём украденные деньги», «продление SIM — сейчас придёт код», «войдите в мой iCloud», «скинь реквизиты».

**Честно о границах:** исправления делали, глядя на этот же набор, поэтому вторая цифра оптимистичнее, чем будет на новых сообщениях. Независимая проверка — сообщения, которые принесут участники пилота. Пропущенные: «оплачу через OLX» (без ссылки), «корреспондент Tengri news» (первое письмо без просьбы), «Интерпол вернёт деньги». Ложная тревога: настоящее SMS 1414 о школьном питании со ссылкой на незнакомый адрес.
