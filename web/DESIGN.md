# DESIGN.md — Saqta

## Характер
Saqta — семейный щит от телефонных мошенников для людей 55+ в регионах Казахстана и их взрослых детей. Мир — парадный фарфор с кобальтовой сеткой из серванта апы: тёплый белый фарфор, насыщенный кобальт, золотой ободок. Спокойно, торжественно, по-семейному. Избегаем вида «банковского приложения»: щитов, мягких карточек с тенью, вкладок-пилюль, неоновых акцентов.

**Фирменный приём — роспись по краю.** Экран обрамлён как блюдце: тонкая кобальтовая линия, полоса кобальтовой сетки с золотыми точками, золотой ободок. Внутри — чистый тёплый фарфор и тёмный крупный текст. Роспись живёт только на краях: бордюр экрана, ободки кнопок, разделители-орнаменты. Под текстом узора нет никогда.

## Цвета
| Токен | Hex | Где |
|---|---|---|
| `porcelain` | `#FBF8F1` | фон всего экрана (тёплый фарфор) |
| `porcelain-deep` | `#F3EDE0` | заливка полей ввода и тихих строк |
| `cobalt` | `#15308C` | роспись, главная кнопка-кесе, линии, ссылки |
| `cobalt-deep` | `#0C1F63` | шапка, нажатое состояние, заголовки на светлом |
| `gold` | `#B8901E` | ободки, точки сетки, ромбы-разделители |
| `ink` | `#111A3B` | весь основной текст (16:1 на фарфоре) |
| `ink-soft` | `#2C3766` | вторичный текст (10:1), не светлее |
| `scam` | `#C2281A` | только улики, вердикт АЛАЯҚТАР, SOS, новый алерт |
| `warn` / `safe` | `#8A4E00` / `#1B6A3D` | вердикты КҮДІКТІ / ҚАУІПСІЗ |

Красный — только мошенничество. Цвет никогда не единственный носитель смысла: рядом всегда слово (АЛАЯҚТАР, SOS, номер улики).

## Шрифты
Golos Text (Google Fonts, есть все казахские буквы ә ғ қ ң ө ұ ү һ і). Одно семейство.

| Роль | Размер / вес |
|---|---|
| Вердикт, число риска | 48–64px / 900 |
| Заголовок экрана | 34–40px / 900 |
| Подпись микрофона, заголовок блока | 26–28px / 900 |
| Основной текст, кнопки | 20–22px / 600–800 |
| Минимум для любого текста | **18px**, цвет `ink` или `ink-soft` |

Выделяем жирностью или цветом, не новым размером. Никакого серого мелкого текста.

## Форма и отступы
- Линии вместо теней: рамки 2px `cobalt`, разделители 1.5px `cobalt`, двойная линия (кобальт + золото) там, где нужен «ободок».
- Скругления: круг — только кесе и тарелка балла; кнопки и поля — 12px; блоки текста — 16px. Пилюль нет.
- Теней почти нет: одна тень только у кесе-микрофона (предмет, стоящий на столе).
- Внутренний отступ экрана учитывает бордюр: контент не заходит на роспись (≥ 24px от края).

## Компоненты
- **Бордюр экрана** — фиксированная рамка по периметру: кобальтовая линия 2px → полоса сетки 12px → золотая линия 1.5px. Не перехватывает клики.
- **Кесе-микрофон** — круг 176px насыщенного кобальта, золотой ободок 6px, внешнее кобальтовое кольцо 1.5px, белая иконка микрофона. Самый заметный объект экрана. Подпись под ним 28px/900.
- **Разделитель-орнамент** — две кобальтовые линии с золотым ромбом посередине. Отделяет блоки вместо карточек.
- **Вердикт** — тарелка с золотым ободком и шкалой риска, слово-вердикт, схема, сводка. Структура неизменна.
- **Улика** — номер в красном круге в тексте и тот же номер в разборе. Разбор — строки, разделённые кобальтовыми линиями, без карточек.
- **Кнопки** — главная: заливка `cobalt`, золотая внутренняя линия; второстепенная: рамка 2px `cobalt`. SOS: заливка `scam`, белый круг «SOS».
- **Навигация** — текстовые ссылки в шапке, активная подчёркнута золотой линией. Переключатель языка — «ҚАЗ / РУС» текстом.
- **Алерт (новый)** — красная рамка 3px, красная полоса-шапка с именем и вердиктом крупно, появление: выезд сверху и вспышка рамки. **Алерт (старый)** — фарфор, кобальтовая рамка 1.5px, полная непрозрачность, отметка «Қаралды».

## Тексты
Тон родственника, не банка. На «Сіз»/«вы». Казахский по умолчанию, русский — переключателем; подписи никогда не смешивают языки и не содержат пометок вроде «(KK)». Кнопки называют действие: «Айтып беру», «Тексеру», «Балама қоңырау шалу». Ошибка говорит, что случилось и что делать.

## Не делать
- Узор-обои под текстом или широкие полосы сетки через весь экран.
- Лавандовые и бледные оттенки кобальта, полупрозрачный белый поверх кобальта.
- Одинаковые карточки с мягкой тенью, вложенные карточки, вкладки-пилюли, зелёные «онлайн»-точки.
- Текст меньше 18px, серый текст, полупрозрачные (opacity) элементы с текстом.
- Эмодзи вместо иконок; КАПС-надзаголовки над блоками.
- Резкие инверсии и стробоскоп; сигнал тревоги — плавная красная рамка.
