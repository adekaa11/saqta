# Saqta — семейный щит от мошенников

**Saqta** (каз. «сақта» — «сохрани») проверяет подозрительные звонки и сообщения для людей 55+ и сразу зовёт семью, если это обман.

> Банк видит перевод. Saqta слышит обман — до перевода.

Команда **C.L.A.Y** · SPARK Startup Hackathon · трек FinTech & Smart Economy

## Попробовать

| | |
|---|---|
| Telegram-бот | [@Saqta_kz_bot](https://t.me/Saqta_kz_bot) |
| Сайт: проверка (экран апы) | https://saqta-delta.vercel.app/#/check |
| Сайт: экран сына / дочери | https://saqta-delta.vercel.app/#/family |
| Состояние сервера | https://saqta-delta.vercel.app/api/health |

**Сценарий в боте:**
1. Сын или дочь открывает бота → «Я сын или дочь» → получает ссылку-приглашение и пересылает её маме или папе.
2. Родитель нажимает ссылку и присылает боту подозрительное сообщение: текстом, пересылкой, **скриншотом** или **голосовым** пересказом звонка.
3. Бот отвечает вердиктом 0–100 (АЛАЯҚТАР / КҮДІКТІ / ҚАУІПСІЗ), показывает уловки ①②③ с объяснением на казахском или русском и говорит, что делать.
4. Если это мошенники или родитель нажал **SOS**, ребёнку сразу приходит тревога в Telegram.

## Как устроено

```
сообщение / скриншот / голосовое
        │
        ├─ скриншот → текст (Gemini, запасной Groq)
        ├─ голос    → текст (Gemini, запасной Groq Whisper)
        ▼
анализ: языковая модель читает по смыслу  ── Gemini 3.5 Flash-Lite → Groq gpt-oss-120b
        +  правила-страховка (коды из SMS, «безопасный счёт», AnyDesk, «ошибочный перевод»…)
        ▼
вердикт 0–100, улики (только дословные цитаты из текста), советы KK/RU
        ▼
«мошенники» или SOS → тревога семье в Telegram + на странице #/family
```

- Модель решает итоговый риск, но «жёсткие» признаки из правил не дают ей занизить оценку.
- Если Gemini не ответил за 1,5 с, параллельно спрашиваем Groq и берём первый ответ (обычно 2–3 с). Если недоступны все модели, отвечают правила, и бот честно пишет, что проверка была упрощённой.
- Голос на сайте записывается в браузере и расшифровывается на сервере, поэтому работает в любом браузере, включая iPhone, и понимает казахский.
- Улики, которых нет в тексте дословно, сервер отбрасывает: модель не может «выдумать» признак.

## Код

| Путь | Что там |
|---|---|
| `web/src/` | сайт: React 18 + Vite 6 + Tailwind (`pages/Check.jsx` — апа, `pages/Family.jsx` — сын) |
| `web/src/engine.js` | правила-страховка (общие для сайта и сервера) |
| `web/server/handler.js` | API: одна функция Vercel на все `/api/*` |
| `web/server/analyze.js` | объединение модели и правил |
| `web/server/llm.js` | вызовы Gemini / Groq, цепочка запасных моделей |
| `web/server/media.js` | голос и скриншоты → текст |
| `web/server/telegram.js` | Telegram-бот: семьи, проверка, тревоги, SOS |
| `web/server/store.js` | хранилище: Upstash Redis (или память локально) |

Основные эндпоинты: `POST /api/analyze` `{text, family_id?}`, `POST /api/ocr` `{image, mime}`, `POST /api/families/:id/sos`, `GET /api/families/:id/alerts`, `GET /api/stats`, `POST /api/telegram` (вебхук бота).

## Запуск локально

```
cd web
npm install
npm run dev        # http://localhost:5173
```

Без ключей всё работает на правилах. Переменные окружения сервера: `GEMINI_API_KEY`, `GROQ_API_KEY`, `TELEGRAM_BOT_TOKEN`, `KV_REST_API_URL` / `KV_REST_API_TOKEN`. Деплой описан в `web/README.md`.

## Честно о границах

- Бесплатные тарифы моделей иногда перегружены: тогда ответ занимает до ~10 с или отвечают правила.
- Звонок Saqta не слушает сама: человек пересказывает его голосом или текстом.
- Точность на реальных сообщениях измеряем отдельным тестом (результаты будут в презентации 2-го тура).
